# 研究归档 · 2026-08-02

本目录归档了 2026-08-02 研究窗口的全部量化研究产出，按主题组织。每个主题包含三类内容：

- **报告/** — HTML 可视化报告（浏览器打开，图表基于 ECharts，CDN 用 npmmirror）
- **数据/** — CSV / TXT 回测明细数据
- **脚本/** — 可复现的 Python 脚本（依赖 `akshare`、`pandas`、`numpy`，虚拟环境 `~/stock_env`）

> 数据源：AkShare 日线（前复权）。RSI 统一采用 **Wilder 平滑法**（`ewm(alpha=1/14)`），与同花顺/东财一致。

### 01_多因子10组合回测

- 报告：`多因子策略_10组合回测_蒙特卡洛.html`（随机池）、`优质股_10组合回测_蒙特卡洛.html`（优质池）
- 数据：`优质股_10组合_操作清单.txt`、`10组合_近一年操作记录.txt`
- 脚本：`mc_screen_quality.py`（优质股筛选）→ `mc_quality_backtest.py`（回测）→ `mc_quality_report.py`（报告）
- 结论：优质池中基本面因子（低波动+量能稳定）占优，防御型配置年化 +17% vs 进攻型 -22%；MC 中位年化 +1.7%，3年亏损概率 45%

### 02_国电南瑞买卖点
单票 5552 组买卖信号矩阵回测（24买×23卖 + 参数网格），寻找最优买卖点。

- 报告：`国电南瑞_WilderRSI_买卖点回测_蒙特卡洛.html`（✅ 正确版）、`国电南瑞_买卖点回测_SMA旧版.html`（⚠️ SMA RSI 错误版，仅存档对照）
- 数据：`国电南瑞_WilderRSI_*.csv`（正确版全套）、`国电南瑞_*.csv`（旧版）
- 脚本：`nari_backtest_v2.py`（回测）→ `nari_mc_report_v2.py`（MC）→ `nari_export_v2.py`（CSV）→ `nari_html_v3.py`（报告）
- 结论：最优策略 RSI<40 买 / 跌破MA60 卖（SL10%/TP20%/25日），年化 +18.5%、胜率 83%、回撤 -10.3%
- ⚠️ 重要教训：旧版误用 SMA RSI（偏高约15点）导致结果失真，已全部用 Wilder 重算

### 04_科技vs消费周期对比
历史类比法：消费股（茅台/五粮液/伊利/海天）2015-2026 完整周期 vs 科技股（海康/立讯/京东方/中兴）2022 底部以来，周期底部对齐叠加。

- 报告：`科技股vs消费股_周期对比_走势判断.html`
