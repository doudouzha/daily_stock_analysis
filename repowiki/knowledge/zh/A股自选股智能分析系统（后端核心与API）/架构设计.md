项目采用多入口、分层清晰的单体架构：
- 入口层：`main.py` 是CLI主调度器，通过 `argparse` 暴露 --serve/--webui/--schedule 等模式；`server.py` 和 `webui.py` 分别作为 uvicorn 启动 FastAPI 的便捷脚本。
- API层：`api/app.py` 通过 `create_app()` 工厂构建 FastAPI 实例，注册 `/api/v1` 路由、CORS、认证中间件与错误处理器，并托管 Vite 构建的前端静态资源（SPA回退 + assets安全校验）。
- 业务层：`src/` 下按职责划分——`agent/`（Agent编排、工具、策略）、`core/`（市场复盘、交易日历、Pipeline）、`services/`（领域服务如 analysis_service、portfolio_service、backtest_service）、`repositories/`（SQLite持久化）、`llm/`（LiteLLM/Hermes本地后端抽象）、`data_provider/`（akshare/yfinance/tushare等多数据源适配器）、`notification_sender/`（多通道通知）。
- 前端层：`apps/dsa-web` 为 React+Vite+TypeScript SPA，`apps/dsa-desktop` 为 Electron 桌面打包产物。
- Bot层：`bot/` 实现钉钉/飞书/Discord等平台命令分发，通过 `dispatcher` 统一路由到 `commands/` 下的子命令。
- 配置与部署：`src/config.py` 单例管理全局配置（.env + dataclass），`docker/` 提供 Dockerfile 与 compose，`scripts/` 包含构建/测试/CI脚本。
依赖方向严格自顶向下：API → services → repositories/data_provider/llm，CLI → core/pipeline → services，Bot → services，前端仅通过 /api/v1 访问后端。
