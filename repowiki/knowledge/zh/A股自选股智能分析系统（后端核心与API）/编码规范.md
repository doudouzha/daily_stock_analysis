- 所有模块以 `# -*- coding: utf-8 -*-` 开头并使用中文文档字符串描述职责与用法。
- 配置项通过 `src/config.py` 中的 dataclass + .env 加载，对外暴露类型安全的属性访问而非直接读环境变量。
- API路由按功能拆分为 `api/v1/endpoints/*.py`，对应的请求/响应模型放在 `api/v1/schemas/*.py`，通过 `router.py` 统一挂载。
- 外部依赖（如 pipeline、broker、LLM后端）采用延迟导入（lazy import）以避免启动时冷路径开销，并通过 `_bootstrap_environment()` 保证 .env 已加载。
- 异常处理遵循「单股失败不影响整体」原则，在 CLI 和 API 层均使用 try/except 包裹并记录警告日志后继续执行。
- 日志统一通过 `src.logging_config.setup_logging` 初始化，区分 console/file handler 并根据 log_prefix 区分不同进程输出。
